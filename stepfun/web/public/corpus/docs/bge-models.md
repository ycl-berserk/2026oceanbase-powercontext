# BGE 中文向量模型

BGE（BAAI General Embedding）是智源研究院开源的一系列嵌入模型，中文场景常用 `bge-small-zh-v1.5`、`bge-base-zh-v1.5`、`bge-large-zh-v1.5`，参数量分别约 2400 万、1 亿、3 亿。small 版本输出 512 维向量，在中文语义相似度任务上表现不错，同时体积适合端侧。

BGE 的训练方式是对比学习：把语义相近的句子拉近、无关的推远，因此它对"同义改写"比较敏感。使用时要注意 pooling 方式——BGE 系列用 CLS pooling（取 [CLS] token 的输出），并对向量做 L2 归一化，之后用余弦相似度或内积检索。

BGE v1.5 的一个重要改进是加入了指令前缀（instruction）机制：检索短查询时可以给查询加上"为这个句子生成表示以用于检索相关文章："之类的前缀，效果略有提升。是否加前缀要和训练时保持一致，端侧为了简化通常直接不加，用同一套方式处理文档与查询即可。

在浏览器里用 BGE 需要 ONNX 版本。社区维护的 `Xenova/bge-small-zh-v1.5` 提供了 fp32、fp16、int8 等多种权重文件，可以直接被 Transformers.js 加载。模型体积（onnx 权重）大致是：fp32 约 90 MB、fp16 约 45 MB、int8 约 23 MB，压缩比接近 4 倍。

选型建议：中文知识库优先 BGE 中文系列；中英混合或资源极度受限时可以用 all-MiniLM-L6-v2（384 维，英文更强）。无论选哪个，都要在技术说明里写清模型来源、版本与维度，方便复现。
