# seekdb 是什么

seekdb 是 OceanBase 推出的 AI 原生检索数据库，把关系数据、向量、全文、JSON 与 GIS 放进同一个引擎。它的定位是"给 agent 与端侧应用做检索底座"：不需要再拼一个向量库加一个搜索引擎，向量近邻与全文匹配可以在一条 SQL 里完成，再由数据库自己做结果融合。

seekdb 与 OceanBase 的关系可以理解为同一套内核的两个形态。OceanBase 是分布式、多租户的版本，适合集群部署；seekdb 是轻量版本，可以嵌入式运行（进程内），也可以作为本地 server 以 MySQL 协议对外提供服务，单机即可跑起来。因此它既能塞进桌面应用做本地知识库，也能放在服务器上做检索服务。

关键能力包括：HNSW 向量索引、全文索引（支持中文 ik 分词）、稀疏向量与 BM25、`DBMS_HYBRID_SEARCH` 混合检索、以及 `dbms_index_manager.refresh()` 这样的索引刷新管理。对端侧应用来说，它最有价值的一点是"数据不出本机"：向量和原文都留在用户设备上。
