# RRF 倒数排名融合

RRF（Reciprocal Rank Fusion，倒数排名融合）是多路召回常用的融合算法。它不需要两路分数的量纲一致，只看各自的名次：对每一路结果，第 r 名的贡献记为 `1 / (k + r)`，其中 k 是平滑常数，常见取值是 60；同一文档在多路里出现就把分数相加，最后按总分排序。

这样做的好处是稳健。向量距离是余弦相似度或内积，全文是 BM25 或 TF-IDF，两者数值范围完全不同，直接加权求和需要调归一化参数；而 RRF 只依赖排名，天然规避了量纲问题。k 越大，名次之间的差距被压得越平，融合结果越"平均"；k 越小，靠前的结果话语权越大。

在 seekdb 的混合检索里，`rank` 字段可以写成 `{ "rrf": { "rank_window_size": 40, "rank_constant": 60 } }`。`rank_window_size` 决定每一路参与融合的候选窗口，窗口太小会丢掉本该靠前的结果，太大则增加融合开销。

需要注意 RRF 的局限：它丢掉了分数强度信息。如果某一路给出了极其确信的匹配，RRF 并不会特别奖励它。所以在对精确匹配要求高的场景，可以配合全文的条件过滤（`$contains`）先缩小候选，再用 RRF 排序。
