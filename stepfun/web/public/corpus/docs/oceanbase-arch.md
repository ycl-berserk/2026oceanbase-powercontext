# OceanBase 架构与多租户

OceanBase 是原生分布式关系数据库，采用 shared-nothing 架构：数据按分区打散到多台 OBServer，每个分区有多个副本，通过 Paxos 协议保证一致性。集群里还有一个总控服务（RootService）负责调度、负载均衡与副本管理。

多租户是 OceanBase 的核心设计。一个集群可以创建多个租户，每个租户在逻辑上是一套独立的数据库实例，拥有自己的资源配额（CPU、内存）、连接串与用户体系。租户之间资源隔离，互不影响。这对云上场景很关键：同一套物理集群可以同时服务多个业务方。

存储引擎使用 LSM-Tree：写入先进入内存表（MemTable），再转储成 SSTable，后台合并（compaction）消除冗余。这个结构让写入吞吐很高，代价是读放大与合并开销，因此需要关注合并策略与磁盘水位。

对 seekdb 来说，它复用了 OceanBase 的内核能力（SQL 引擎、存储引擎、向量/全文索引），但把部署形态简化成单机、可嵌入。理解这一点有助于排查问题：seekdb 的行为习惯、参数体系、错误码基本沿用 OceanBase 的那一套。
